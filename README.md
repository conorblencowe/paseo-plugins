# Paseo plugins

Plugins for [Paseo](https://paseo.sh).

- [Buildkite status](buildkite-status/README.md): Buildkite builds, steps and logs for your branch, with retries and sending failures to an agent.
- [Sidebar agent tree](sidebar-agent-tree/README.md): each sidebar workspace's agents and their status.
- [Sidebar archive button](sidebar-archive-button/README.md): one-click archive on sidebar workspace rows.
