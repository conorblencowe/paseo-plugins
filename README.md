# Paseo plugins

Plugins for [Paseo](https://paseo.sh). Install one with:

```bash
paseo plugin add github:conorblencowe/paseo-plugins:<plugin>
```

## [buildkite-status](buildkite-status/OVERVIEW.md)

Buildkite builds, steps and logs for your branch, with retries and sending failures to an agent.

## [sidebar-agent-tree](sidebar-agent-tree/OVERVIEW.md)

Each sidebar workspace's agents and their status.

![A sidebar workspace row with its two agents listed underneath, one running](sidebar-agent-tree/assets/screenshot.png)

## [sidebar-archive-button](sidebar-archive-button/OVERVIEW.md)

One-click archive on sidebar workspace rows.

![A hovered sidebar workspace row with the archive button beside the menu](sidebar-archive-button/assets/screenshot.png)
